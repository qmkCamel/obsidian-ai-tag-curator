# 产品 TODO：从标签关系探索到持续治理

更新日期：2026-10-28。当前产品基线为 0.5.0；本文件记录后续产品方向，不代表功能已经实现，也不承诺版本号或发布日期。

产品定位：帮助 Obsidian 用户看懂标签实际如何使用，并持续整理自己的标签体系。核心任务是“理解关系 → 比较笔记证据 → 作出整理判断 → 审查执行 → 核对结果与恢复”。目标用户是已有标签积累、查找或整理开始困难的个人库使用者；规模、频率和付费意愿仍需访谈/任务实测验证。

依据：[同类产品、规模与维护快照](../openspec/changes/add-tag-relationship-graph/product-comparison.md)、[当前提案](../openspec/changes/add-tag-relationship-graph/proposal.md)、[实现任务](../openspec/changes/add-tag-relationship-graph/tasks.md)。本文件维护产品优先级，当前 change 的 tasks 维护实现完成状态；不要在两处重复勾选同一实现任务。

## 暂缓与升级条件

3D、全库无上限布局、自由白板编辑器、自动定时清理、语义边直接驱动修改、云账号/协作和移动端图谱不纳入当前 change。更大的渲染引擎只在局部图与关系表无法完成经验证的任务时评估；移动端另需交互、资源和真实设备验收。AI 功能以是否改善判断和完成任务为依据，不以功能数量或竞品更新频率排序。

衡量顺序：先验证证据正确、无误导修改与恢复可靠，再比较任务完成率/时间/步骤，最后观察自愿参与用户是否重复使用。遥测、自动监控和外部用户联系均需单独明确方案，不由本 TODO 自动引入。
