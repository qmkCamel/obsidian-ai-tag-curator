## 自动化覆盖范围

- 范围前置、空范围、递归开关、默认 50 与 1-200 上限、禁止静默截断。

## 真实 Obsidian smoke

环境：Obsidian `1.12.7`，系统临时目录中的隔离测试仓库，本地确定性 OpenAI-compatible mock provider。

- 设置页反馈入口可见，点击后正确打开 `github.com/qmkCamel/obsidian-ai-tag-curator/issues/new`。
- 默认范围为活动笔记父文件夹；3 个 Markdown 文件、递归开关、请求数量和单批上限展示正确。
- 生成中显示读取/AI/计划/取消正交进度和可读的计费提示。
- 最小化后进度固定在右下角；运行期间可直接打开范围外笔记，进度、展开和取消控件持续可见。
- 完整预览展示 3 个文件、长路径、frontmatter/inline/AI 来源、风险色与开关、应用前后标签。
- 默认低风险计划应用到 2 篇笔记，新增 5 个 frontmatter 标签，正文未改写，范围外笔记未修改。
- 整批回退恢复应用前快照并移除批次操作记录。
- 立即取消后，已读取笔记的 inline 同步项仍可审查；未完成 AI 项标记为 cancelled/unavailable。
- 浅色与深色主题、约 1400px 宽窗口、552px 窄窗口、命令面板键盘路径和长路径换行均通过视觉检查。
