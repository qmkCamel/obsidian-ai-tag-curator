# 标签关系探索（未发布工作区功能）

执行命令 **打开标签关系图 / Open tag relationships**，或在标签管理中切到**关系图**。已有索引即可使用，无需 API key 或活动笔记；无索引时显式刷新。首次进入显示完整范围标签搜索，不自动生成概览。

1. 搜索精确标签，点击标签查看一跳邻域；也可在原标签详情点击“查看关系”。低频标签不受概览前 200 个节点限制。
2. “查看范围概览”展示当前范围前 50/100/200 个标签，默认 200。共同文件阈值默认 2，可设为正整数；来源、阈值、上限和层级修改需显式生成，旧结果仍标注原口径。
3. 输入或从完整搜索选择 A/B，比较**共同、仅 A、仅 B**。两端都存在时，零交集也是有效结果；重复端点或失去成员的端点不可比较。
4. 检查三组分页文件证据，每页 50。图形、关系表和候选节点列表均可进入详情；证据笔记在旁边打开，保留工作台。
5. “带入整理”只保留比较上下文，不勾选标签、不创建写入计划。另行选择改名/合并、目标和范围，沿用已有审查与确认。取消可返回同一比较；执行/撤销后旧证据标记过期，显式刷新再核对。

**怎样读统计：**节点大小对应去重文件数。共现边使用两标签共同文件数；交并比为共同数除以两边文件集合的并集。两个覆盖率的分母分别是 A、B 的文件数。例如 A=100、B=10、共同=10，交并比为 0.1，覆盖率为 10%/100%。这描述使用范围，不等于同义、因果或合并建议。浏览来源与证据分组也不代表修改范围。

**层级是独立关系：**可选虚线箭头只连接真实存在的直接 `a → a/b`，不虚构缺失父标签、不跨层、不累计子标签文件；同一对可以同时有共现和命名层级两条关系。

**显示范围与预算：**概览最多 200 节点，一跳邻域最多 50 节点；共现与层级合计最多 800 条边。显示合格标签数、候选数、候选内关系数和隐藏原因，不声称知道候选外全库边总数。统计使用全部匹配文件，不逐文件抽样；超过 100 万原始成员、32 MiB 最小输入、1000 万次标签对更新或 10 秒期限时受控停止，建议缩小范围。

**来源与新鲜度：**全部来源包含 metadata-only 成员；属性/正文只接受对应来源。未开启正文采集时，正文查询显示不可用及设置入口，开启后需刷新。成功生成关系不会使旧索引变新；最后索引时间来自索引本身。范围/排除变更立即清除旧图与证据，同范围失败或取消保留旧结果。

**交互与环境：**支持图形缩放/平移/适配、图表切换、键盘与深浅主题。Worker 无法启动时，显式“使用关系表重试”，采用相同统计预算且可取消，不在主线程运行力导向布局。移动端显示当前不支持图谱，并提供原标签列表。查询、布局与交接上下文只保留于当前会话。

仍使用 `main.js`、`manifest.json`、`styles.css` 三件发布资产；没有额外 Worker 文件、CDN 或新 AI 请求。当前改动尚未打 tag 或发布；测试范围、真实宿主证据和剩余产品验证见[验收记录](verification/tag-relationship-graph.md)。
