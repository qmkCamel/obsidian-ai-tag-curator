## Why

0.5.0 已能浏览单个标签的关联笔记，但用户无法直接回答“哪些标签经常一起使用、共同与各自独有的笔记是什么、是否值得进入整理审查”。本 change 将此前暂缓的标签图谱收敛为本地、只读、证据可追溯的关系探索，并把判断上下文衔接到既有标签管理流程。

技术调研及取舍见 [research.md](research.md)，同类产品、公开规模、维护情况与采纳决定见 [product-comparison.md](product-comparison.md)，后续阶段见 [产品 TODO](../../../docs/product-todo.zh-CN.md)。基线为 `main` / `664712386524cc7777101b7998fa9f49801d498f`，版本 0.5.0。2026-10-28 根据产品对比修订本方案；仅更新设计，不代表功能实现或发布。

## What Changes

- 在现有标签管理工作台增加“关系图 / Relationships”页签与直接打开命令。独立打开先显示范围摘要和完整范围标签搜索；从标签详情进入时直接查看该标签的一跳邻域，范围概览作为显式可选入口。
- 以精确标签身份为节点，以同篇笔记中的共同出现为无向边；节点统计、边权和证据均按去重文件计算。提供共同文件数与 Jaccard 交并比，明确共现不等于同义、因果或合并建议。
- 可选显示已有标签之间的直接 `/` 父子关系，使用独立边类型及图例，不创建隐含父标签，不把子标签的文件计入父标签。
- 支持范围、来源、共同文件数阈值、节点上限、搜索聚焦、缩放和平移；点击节点看关联笔记，点击共现边看共同笔记，提供等价可键盘操作的关系表。
- 增加独立标签对比较：共同文件、仅 A、仅 B、交并比及两个方向的覆盖率。允许从搜索选择无共现或未入图的标签对；零交集不生成虚假边，也不排除同义的可能。
- 提供“带入整理”导航，把标签对、查询口径与快照身份保留为工作台只读上下文。用户在管理流程中另行选择操作、来源/目标和范围，复用现有审查、历史与恢复；比较结果不是 mutation intent。
- 重用已有索引及其新鲜度，不新增正文扫描或 AI 调用。图谱计算独立取消、限制资源、拒绝晚到结果；失败保留同一范围内上次有效结果。
- 第一阶段限定桌面只读探索；不增加图内写入、AI/embedding 语义边、全库无上限布局、导出、自动聚类、层级迁移或核心 Graph 私有 API 注入。
- 产品验收覆盖“找到关系 → 比较证据 → 进入整理审查 → 核对结果/撤销”；记录任务时间、步骤、判断和恢复结果，不能仅以出图或帧率判定产品价值。保存查询、热力图和 AI 建议进入后续 TODO。

## Capabilities

### New Capabilities

- `tag-relationship-model`：精确标签、范围和来源过滤、共现计数、交并比、差集与双向覆盖率、层级边、可复核文件证据及显示截断语义。
- `tag-relationship-graph`：局部优先入口、概览与邻域、标签对比较、只读上下文交接、关系表、主题与键盘交互。
- `tag-graph-computation`：有界异步计算、取消与版本隔离、索引新鲜度、失败保留、生命周期和性能验收。

### Modified Capabilities

无。`openspec/specs/` 中现有正式规格无需改变；工作台和索引能力仍位于已实现但未归档的 `add-tag-management-workbench` change，本提案以新增能力扩展，不复制其规格或抢先归档。

## Impact

- 新增 `src/graph/` 中的关系投影、任务控制、Worker、SVG 展示和可访问关系表；调整 `TagManagementView` 的页签与稳定渲染区域、管理适配器及入口；文案沿用 `src/ui/managementLabels.ts` 的中英文约定。
- 复用 `TagIndexService`、`normalizeTag`、范围/排除策略及精确文件打开能力；扩展只读快照元数据，不改变索引持久化格式、操作日志或写入授权。
- 工作台协调层保存会话内的比较上下文与返回入口；关系计算服务和图渲染器不持有写入接口。来源筛选和证据列表不直接转换成写入文件白名单或 occurrence 选择。
- 拟采用按模块打包的 `d3-force`、`d3-selection`、`d3-zoom` 和相应开发类型，使用 SVG 展示有界图。依赖、许可证、包体积及宿主 Worker 兼容性需在实现阶段验证。
- Worker 构建须保持现有 `main.js`、`manifest.json`、`styles.css` 发布安装闭包；不运行时访问 CDN。
- 增加统计/竞态测试、浏览器交互性能证据、最低支持版本及当前桌面 Obsidian 主窗口/弹出窗口验收。移动端未验收前只提供已有标签列表入口和明确状态。
