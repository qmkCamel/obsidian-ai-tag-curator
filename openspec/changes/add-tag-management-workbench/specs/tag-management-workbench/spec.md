## ADDED Requirements

### Requirement: 工作台独立于 AI 和活动笔记

系统 SHALL 提供原生工作区标签管理视图，命令和 ribbon 入口复用已有实例；浏览、范围设置、手动整理和历史 SHALL NOT 依赖 provider、API key 或活动 Markdown 文件。

#### Scenario: 未配置 AI 打开工作台
- **WHEN** 用户在没有活动笔记且未配置 API key 时打开工作台
- **THEN** 系统显示标签/历史页签及真实索引状态
- **AND** 不测试模型、不发送网络请求、不自动改写 Markdown

#### Scenario: 重复打开与关闭
- **WHEN** 用户从命令和 ribbon 连续打开再关闭工作台
- **THEN** 系统复用视图并释放该视图监听
- **AND** 已提交的写入仍由插件服务管理，关闭视图不丢弃恢复状态

### Requirement: 标签列表采用真实去重统计和明确分页

工作台 SHALL 按标签身份合并并去重文件数，显示来源文件数而不是把 legacy count 显示为正文次数；列表每页 100 项，相关笔记每页 50 项。

#### Scenario: 同文件包含属性和重复正文标签
- **WHEN** 一篇笔记同时有 frontmatter 标签和多个同名正文 token
- **THEN** 标签总关联文件数增加一，属性和正文文件数各增加一
- **AND** 不从索引伪造精确正文 token 次数

#### Scenario: 大列表与过滤
- **WHEN** 索引有 10,000 个标签且用户输入子串并切换排序
- **THEN** UI 只渲染当前页，过滤不读取笔记或调用 AI
- **AND** 使用去重文件数与稳定标签排序，不把搜索词解释为正则

### Requirement: 浏览选择不隐式扩大写入范围

系统 SHALL 明确区分分页选择、来源浏览过滤和实际改写来源，搜索/来源/范围改变时清空选择；翻页 SHALL 保留选择并显示总数。

#### Scenario: 全选当前页后翻页
- **WHEN** 用户全选当前页并翻页
- **THEN** 只选中原当前页条目，不自动选中隐藏的全部结果
- **AND** 工具栏显示跨页已选总数

#### Scenario: 来源筛选后发起改写
- **WHEN** 用户按正文来源筛选并对一个标签发起改写
- **THEN** 审查仍明确展示属性和正文两种来源的差异供选择
- **AND** 来源浏览过滤不能充当未展示的写入授权

### Requirement: 详情使用精确标签文件集合

系统 SHALL 展示精确标签的相关笔记，不将宿主含子标签的搜索结果冒充精确变更文件集合。

#### Scenario: 查看有子标签的标签
- **WHEN** 用户查看 project 且库内存在 project/active
- **THEN** 精确详情不把仅含 project/active 的笔记计入 project
- **AND** 子标签存在情况另行提示，打开文件不执行任何标签修改

### Requirement: 空态和窄窗口具备完整交互

视图 SHALL 区分无索引、空库、筛选无结果、扫描中、过期和错误；360px 宽及键盘路径 SHALL 可完成主流程。

#### Scenario: 窄窗口查看长标签详情
- **WHEN** 视图宽度小于 900px 且路径或标签很长
- **THEN** 使用列表/详情切换与返回，文本不遮挡操作按钮
- **AND** 关闭审查后焦点返回发起入口，异步状态有可访问说明

#### Scenario: 索引不可用
- **WHEN** 没有可用索引或刷新失败
- **THEN** 显示对应状态与恢复操作，不显示虚构的零标签成功结果
- **AND** 已有历史仍可查看
