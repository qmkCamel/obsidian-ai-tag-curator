## 为什么

插件仍处于早期阶段，用户遇到配置问题、推荐不准确或有使用建议时，设置页缺少一个直接可发现的反馈入口。增加明确入口可以降低反馈成本，同时继续保持插件无遥测、无后台服务的隐私边界。

## 变更内容

- 在设置页增加“提供反馈”设置项。
- 提供一个按钮，在系统浏览器中打开项目 GitHub 的新建 Issue 页面。
- 为入口提供简体中文和英文文案。
- 不自动收集、上传或预填用户的 Vault、API key 或模型配置。

## 能力

### 新增能力

- `settings-feedback-entry`：用户可以从插件设置页直接进入公开反馈渠道。

### 修改能力

无。

## 影响

- 修改 `src/settings/SettingsTab.ts` 和 `src/ui/labels.ts`。
- 扩展设置页端到端测试，验证反馈入口和外部链接。
- 不新增运行时依赖、持久化字段、网络请求或遥测。
